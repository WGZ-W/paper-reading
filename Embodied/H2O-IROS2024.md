

# 论文详解：H2O——从人类动作到人形机器人的实时全身遥操作

**论文：**[Learning Human-to-Humanoid Real-Time Whole-Body Teleoperation](https://arxiv.org/html/2403.04436)，He 等，2024。

**核心结论：**H2O 让操作者站在普通 RGB 摄像头前运动，由三维人体姿态估计器提取动作目标，再让一台 Unitree H1 人形机器人实时跟随。它的关键并非把人的关节角直接复制给机器人，而是先筛选机器人能够执行的人类动作，再用强化学习训练兼顾动作跟踪与站立稳定性的控制策略。

## 1. 论文要解决什么问题

全身遥操作要求机器人同时模仿人的手臂、躯干和腿部动作。困难有三层：

1. **人体与机器人结构不同。** 即使姿势看起来相似，直接复制关节角也可能使机器人的手脚落在错误位置。
2. **能摆出姿势，不等于能完成动作。** 人类动作数据中有些动作超出机器人的腿长、关节力矩或平衡能力。
3. **仿真控制器未必能上真机。** 仿真可以读取所有刚体状态和接触力；真实机器人必须依靠实际可获得的状态，并容忍模型误差与控制延迟。

作者因此把工作拆成“**制作适合机器人的动作数据**”和“**训练可部署的跟踪策略**”两个阶段。[问题与贡献](https://arxiv.org/html/2403.04436)

## 2. H2O 的完整流程

**离线准备：人类动作 → 机器人可学的动作**

- 数据来自 **AMASS**，约 40 小时、1.3 万段人体动作。
- 作者先调整 SMPL 人体模型的身材参数，使其骨架比例更接近 H1；再通过优化，让机器人对应的 **12 个关节位置**尽量贴合人体动作。这样得到约 **1 万段**重定向动作。
- 重定向只处理运动学匹配。作者随后在仿真中训练一个能读取完整状态的“特权模仿器”，逐段尝试跟踪这些动作，并剔除它跟不上的序列。最终保留约 **8,500 段**动作，形成训练集。作者把这一筛选过程称为 **sim-to-data**。[动作重定向与筛选](https://arxiv.org/html/2403.04436)

这里的“可行”有一个准确含义：**该仿真模仿器在设定条件下能够跟踪**。它不是对某段动作在物理上绝对可行或不可行的证明。

**在线运行：操作者动作 → 机器人关节目标**

RGB 摄像头拍摄操作者；HybrIK 估计三维人体姿态；控制策略读取人体动作目标和机器人的自身状态，输出 **19 个关节目标位置**；底层 PD 控制器再将目标位置转换为驱动力矩。策略每一步都重新观察和决策，因此可以连续跟随操作者，而不必预先知道整段动作。[策略设计](https://arxiv.org/html/2403.04436)

## 3. 控制策略具体学什么

H2O 将控制表述为**目标条件强化学习**，使用 PPO 训练一套可跟踪多种动作的策略。

策略的机器人自身状态包括关节位置与速度、机身线速度与角速度、重力方向和上一时刻动作。人体目标则采用 **8 个位置点**——双肩、双肘、双手和双脚踝——以及参考点与机器人当前点的位置差、参考点速度。这种表示让策略知道“目标在哪里”和“目前差多少”。虽然输入只选取了部分位置点，仿真训练的奖励仍会衡量全身关节与刚体的姿态、位置和速度跟踪误差。[状态与奖励设计](https://arxiv.org/html/2403.04436)

奖励还会惩罚越过关节或力矩限制、动作变化过快、脚底打滑和绊倒等行为。训练期间，作者随机改变地面摩擦、机器人质量与重心、PD 增益、控制延迟和地形，并施加外力扰动。这些设计的目的，是让策略既模仿动作，又在真实硬件误差下保持稳定。[奖励与域随机化](https://arxiv.org/html/2403.04436)

## 4. 实验结果说明了什么

论文在约 **1 万段未经最终筛选的重定向动作**上评估仿真跟踪。这里的“成功”指整段跟踪过程中，平均身体位置偏差未超过论文设定的 **0.5 米阈值**；它不是某个现实任务的完成率。[指标定义](https://arxiv.org/html/2403.04436)

| 仿真策略 | 跟踪成功率 | 说明 |
| --- | ---: | --- |
| H2O 完整方案 | **72.5%** | 筛选动作数据，使用完整目标状态 |
| 去掉 sim-to-data 筛选 | 67.9% | 直接用重定向动作训练 |
| 简化目标状态 | 53.2% | 只提供所选目标点的位置 |
| 特权模仿器 | 85.5% | 可读取完整仿真状态，**不能直接部署** |

两项消融支持作者的主要设计：**筛除难以跟踪的动作**带来 4.6 个百分点的提升；**加入位置误差和目标速度**比只给目标位置提升 19.3 个百分点。将干净训练集从 0.1% 增至 100% 时，成功率也从 **52.0% 升至 72.5%**，表明动作数据规模仍有作用。[表 III、表 IV](https://arxiv.org/html/2403.04436)

真机部分展示了行走、后跳、踢球、挥手、拳击、推婴儿车及受到外力后保持平衡等动作。**这些是真实机器人演示；论文没有像仿真表格那样报告一套真机动作的整体成功率或跟踪误差分布。**[真机实验](https://arxiv.org/html/2403.04436)

## 5. 如何理解“只用 RGB 摄像头”

这个说法主要针对**采集操作者动作**：人不必穿动作捕捉服、佩戴标记或使用外骨骼。真机部署的完整系统仍读取 H1 自带传感器，而且论文使用了 **50 Hz 外部动作捕捉系统估计机器人机身线速度**；人体姿态估计运行于 30 Hz，机器人其他自身状态来自 200 Hz 的内置传感器。因此，论文并未展示一套完全只靠单个 RGB 摄像头、无需外部定位设备的真机系统。[部署细节](https://arxiv.org/html/2403.04436)

## 6. 贡献与局限

这篇论文最有价值的想法是 **sim-to-data**：当人类动作库与机器人能力不匹配时，先让仿真控制器尝试，再把难以跟踪的数据排除，最后训练真正要上机器人的策略。它也证明了用统一强化学习策略跟踪多种全身动作，并直接迁移到真实 H1 进行实时遥操作的可行性。

仍需谨慎看待其适用范围：单目姿态估计有噪声和视角偏差；系统存在摄像头、姿态估计与控制链路的延迟；复杂动作受机器人的机械能力限制；真机还依赖外部速度测量。作者也指出，扩大动作覆盖范围与保持稳定性之间仍有权衡。[讨论与局限](https://arxiv.org/html/2403.04436)

**读完可记住的一句话：**H2O 的成功来自“**先把人类动作变成机器人学得会的数据，再让强化学习策略在真实可用的状态下稳健跟踪**”；RGB 摄像头降低的是操作者的动作采集门槛。
