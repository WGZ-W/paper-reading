# 空中视觉语言导航

## 核心问题

给定自然语言路线描述，无人机如何根据沿途观测完成三维导航？需要同时考虑地标识别、语言进度、飞行高度、障碍物、长时记忆、偏航恢复和终点停止。

## 阅读路线

1. 阅读 [AerialVLN](../papers/2023-aerialvln/index.md)，建立观测、动作、数据划分和评估指标的基本认识。
2. 比较笔记中的 Seq2Seq 与 CMA，理解历史状态和跨模态注意力如何参与动作预测。
3. 研究 LAG 如何构造偏航后的监督动作，比较它与直接朝最终目标走最短路的区别。
4. 阅读 [OpenFly](../papers/2026-openfly/index.md)，理解自动轨迹与指令生成、多引擎场景，以及基于地标的关键帧记忆。
5. 对照两篇论文的数据规模、路线长度、动作空间和评估指标，再区分数据工程与模型改进的作用。
6. 后续补读连续环境 VLN、语言对齐路点监督、VLA 与空中对话导航；相关工作尚无独立精读笔记。

## 已有论文与方法

| 论文 | 任务或数据贡献 | 方法切入点 | 主要限制 |
| --- | --- | --- | --- |
| [AerialVLN](../papers/2023-aerialvln/index.md) | 城市级空中 VLN，25 个场景，完整集与小场景子集。 | CMA 基线与 LAG 路线监督。 | 成功率低；只报告仿真结果；LAG 结果位于小场景子集。 |
| [OpenFly](../papers/2026-openfly/index.md) | 多引擎自动数据工具链，18 个场景、100K 条航线。 | OpenVLA 初始化、地标关键帧选择与视觉 Token 压缩。 | 平均路线较短，样本分布不均；实机仅 23 个任务且依赖外部 PC 推理。 |

## 两篇论文如何对照

| 维度 | AerialVLN | OpenFly |
| --- | --- | --- |
| 数据采集 | 人工飞行轨迹与人工指令标注。 | 点云路径搜索与 VLM 指令生成，保留人工质检。 |
| 数据规模 | 8,446 条路线，平均 661.8 米。 | 100K 条路线，平均 99.1 米。 |
| 核心方法 | LAG 改进偏航后的训练动作监督。 | KS 与 VTM 筛选并压缩历史观测。 |
| 基线动作 | 八类，含水平侧移。 | 六类，不含水平侧移。 |
| 路线指标 | SDTW，关注参考路线相似性。 | SPL，关注长度效率。 |
| 实机证据 | 所读版本没有实机实验。 | 23 个真实任务，模型运行于外部 PC。 |

两者的原论文成功率不应直接横向比较。OpenFly 的 Table 2 中，AerialVLN 方法在 OpenFly 基准上的 SR，才属于同一评测数据下的方法对照。

## 当前理解与待解问题

- **路线忠实度**：指令要求经过特定地标时，终点最短路并不充分，应结合 SR 与 SDTW 判断。
- **动作粒度**：没有预建导航图，但基线仍从八种离散动作中选择，不能等同于连续控制策略。
- **停止与纠偏**：OSR 与 SR 的差距说明部分轨迹接近过目标却未成功停止；如何区分终点识别、停止决策与路径恢复的贡献？
- **泛化证据**：场景、路径长度、天气和传感器条件分别影响多少？支持动态仿真不等于已经验证所有条件下的鲁棒性。
- **数据与记忆**：OpenFly 的收益有多少来自数据规模、路线难度、预训练模型和关键帧模块？能否在控制变量后将短历史记忆扩展到长程路线？

以上是阅读后的研究线索，尚未通过本项目中的实验验证。
