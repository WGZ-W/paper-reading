# 人形机器人全身控制

## 核心问题

人形机器人如何在接触、摩擦和推扰下跟踪参考动作，并用同一个控制器覆盖走跑、侧滚和翻转？评价时需同时观察训练成本、跟踪精度、扰动恢复和实机表现。

## 阅读路线

1. 阅读 [SuperMimic](../papers/2026-supermimic/index.md)，区分参考动作、机器人本体观测和关节设定值。
2. 对比仿真 PPO、模型内 PPO 与通过动力学反传的更新，理解训练预算、rollout 吞吐和想象步数各自衡量什么。
3. 结合 critic 消融与实机展示，区分短时动力学预测、失衡恢复和动作迁移。
