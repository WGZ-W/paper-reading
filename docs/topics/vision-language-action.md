# 视觉语言动作模型与机器人操作

## 核心问题

如何让预训练视觉语言模型根据图像和指令输出低层动作，并用少量示范适配不同机器人、场景和任务？动作表示、数据混合与闭环频率共同影响实机表现。

## 阅读路线

1. 阅读 [OpenVLA](../papers/2024-openvla/index.md)，理解 VLM 如何用自回归 Token 表示末端执行器动作。
2. 对照实机新任务、LoRA 和量化结果，比较语言定位、训练成本和控制频率。
3. 阅读 [OpenFly](../papers/2026-openfly/index.md)，观察同类模型适配到导航时如何处理历史观测和不同动作空间。

| 论文 | 方法 | 评测范围 |
| --- | --- | --- |
| [OpenVLA](../papers/2024-openvla/index.md) | 用实机演示微调图像与语言条件的动作生成模型，每维动作离散为 256 档。 | WidowX 和 Google Robot 直接部署，Franka 少样本适配，LIBERO 仿真。 |

## 待解问题
